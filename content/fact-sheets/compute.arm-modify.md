# Modify an existing Azure Resource Manager template

## Key concepts

- An ARM template is a plain JSON document; the tutorial edits it in Visual Studio Code and saves it as `azuredeploy.json`, and that file path is what you feed to the deploy command later. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-tutorial-create-first-template))
- Three top-level fields matter when you revise a template: `$schema` (points to the JSON schema listing valid properties), `contentVersion` (your own version marker), and `resources` (what gets deployed or updated). ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-tutorial-create-first-template))
- The `$schema` value `https://schema.management.azure.com/schemas/2019-04-01/deploymentTemplate.json#` used in the tutorial is still current: that date exposes all the latest features because no breaking changes have occurred since it was introduced. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-tutorial-create-first-template))
- `contentVersion` accepts any value you like; use it to document significant template changes and to confirm you are deploying the template you meant to. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-tutorial-create-first-template))
- `resources` starts as an empty array `[]` in the starter template, and each entry carries `type`, `apiVersion`, `name` and its properties, for example `"type": "Microsoft.KeyVault/vaults"`. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-tutorial-create-first-template)) ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- Resource Manager resolves parameter values before deployment operations begin, replacing every parameter use in the template with the resolved value. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- Parameters make one template reusable across environments; the minimum declaration is a name plus a `type` — `string`, `int`, `bool`, `object`, `array`, or the secure variants `secureString` and `secureObject`. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- Template functions build values; Resource Manager groups them as array, CIDR (in the `sys` namespace), comparison, date, deployment value, lambda, logical, numeric, object, resource, scope and string functions, and you can also declare user-defined functions. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-functions))
- Most functions behave identically at resource group, subscription, management group and tenant scope; only a few are scope-limited, and the documentation flags them in the function lists. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-functions))
- To revise a template you edit and save the JSON, then redeploy it to the same resource group under a new deployment name so the deployment history stays readable. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-tutorial-create-first-template))

## Settings and limits

- Tooling floor: Azure CLI 2.37.0 or later and Azure PowerShell 7.2.4 or later; earlier versions will not run the tutorial's commands. Check with `az --version`. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-tutorial-create-first-template))
- Sign in first with `Connect-AzAccount`, then pick the subscription with `Set-AzContext SubscriptionName` using either the subscription name or its ID. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-tutorial-create-first-template))
- The resource group must exist before you deploy: `New-AzResourceGroup -Name myResourceGroup -Location "Central US"`. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-tutorial-create-first-template))
- Deploy by storing the path in `$templateFile` and running `New-AzResourceGroupDeployment -Name blanktemplate -ResourceGroupName myResourceGroup -TemplateFile $templateFile`. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-tutorial-create-first-template))
- Judge the run by the `ProvisioningState` value in the command output; add the `verbose` switch for resource-level detail and `debug` for deeper troubleshooting. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-tutorial-create-first-template))
- Portal check: open **Resource groups**, tick the box next to the group, and in the **Essentials** section read the status beside **Deployments** (for example **1 Succeeded**); opening the deployment shows its inputs, outputs and the template it used. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-tutorial-create-first-template))
- Clean up by typing the group name into **Filter for any field...**, ticking it, then choosing **Delete resource group**; keep the group if you are continuing the tutorial series. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-tutorial-create-first-template))
- Hard limit: a template may declare at most 256 parameters. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- `allowedValues` holds the permitted values in an array, and a deployment fails during validation when the supplied value is not among them. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- `defaultValue` is used only when the caller supplies no value, and it can be combined with `allowedValues`. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- `minLength` and `maxLength` constrain `string` and `array` parameters (character count vs. item count) and you may set one or both; `minValue` and `maxValue` are the `int` equivalents. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- `secureString` and `secureObject` mark secrets: the value is not saved to deployment history and is not logged. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- `metadata.description` becomes the tip shown for that parameter in the portal deployment form; add it only when it says more than the parameter name does. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- `languageVersion 2.0` adds aggregate type validation constraints usable in `definitions`, `parameters` and `outputs`: `additionalProperties`, `discriminator`, `items`, `nullable`, `prefixItems` and `properties`. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- Object parameters: `properties` maps each property name to a type definition and every listed property is required unless its type definition sets `"nullable": true`; `additionalProperties` takes a type definition or boolean and defaults to `true`; `discriminator` combines a `propertyName` with a `mapping` of values to schemas. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- Array parameters: `prefixItems` sets a schema per index and `items` governs elements beyond the last index covered by `prefixItems`; `items` also accepts a boolean and defaults to `true` when unset. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- Scope functions: `managementGroup()` only in management group deployments, `resourceGroup()` only in resource group deployments, `subscription()` in resource group or subscription deployments, `tenant()` at any scope. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-functions))
- Resource functions include `reference`, `references`, `resourceId`, `listKeys`, `listSecrets`, `listAccountSas`, `pickZones`, `roleDefinitions`, `subscriptionResourceId`, `tenantResourceId` and `extensionResourceId`; `providers` is deprecated. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-functions))
- Portal labels: camel-cased parameter names are displayed as space-separated words, so `demoString` shows as **Demo String**. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))

## Compare and choose

- Azure CLI vs Azure PowerShell: both deploy templates; the tutorial's PowerShell path is `New-AzResourceGroupDeployment` with `-Name`, `-ResourceGroupName` and `-TemplateFile`, while the CLI needs 2.37.0+. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-tutorial-create-first-template))
- Deploy vs update: the `resources` array holds resources you deploy *or* update, so re-running an edited template re-applies changed properties to resources already in the group. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-tutorial-create-first-template))
- Default vs required: add `defaultValue` when a sensible fallback exists, such as `[resourceGroup().location]`; otherwise the caller must supply the value. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- One parameter vs an object parameter: grouping related settings into a single `object` parameter reduces the parameter count and exposes values as `parameters('vNetSettings').name`. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- `string` vs `secureString`: choose `secureString` for a secret and `secureObject` when the secret travels inside an object. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- `allowedValues` vs free-form `string`: use `allowedValues` for enums so a wrong choice fails validation instead of reaching the resource. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- `minLength`/`maxLength` vs `minValue`/`maxValue`: the length pair constrains `string` and `array` parameters; the value pair constrains `int` parameters. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- Object shapes: `properties` for known keys, `additionalProperties: false` to reject unknown keys, `additionalProperties` with a type definition to type the extras, `additionalProperties: true` (the default) to allow anything. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- Array shapes and optionality: `prefixItems` for fixed tuples, `items` for the tail, `items: false` to pin the exact length, and `"nullable": true` on a property's type definition to let that member be `null` or omitted. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- Function pick: `parameters()` for parameter values, `variables()` for variables, `deployment()` and `environment()` for deployment context, `resourceGroup()`/`subscription()`/`tenant()`/`managementGroup()` for scope, `concat`/`format`/`uniqueString`/`substring` for strings, `if`/`and`/`or`/`not`/`equals` for logic and comparisons, `filter`/`map`/`reduce`/`sort`/`groupBy` for collections, `reference`/`listKeys` for runtime resource values. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-functions))
- Bicep alternative: Microsoft recommends Bicep for new work because it offers the same capabilities with easier syntax, and its `any()` function exists to clear data type warnings. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-functions))

## Gotchas

- `reference()` and every `list*()` function need the runtime state of a resource, so they cannot appear in the `parameters` section — parameters are resolved before deployment starts. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- Expressions are allowed in a `defaultValue`, but a parameter cannot combine an expression with other parameter properties. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- A `variable` cannot be a `defaultValue`; build the default from another parameter instead, for example `"[concat(parameters('siteName'),'-plan')]"`. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- A value outside `allowedValues` fails the deployment during validation, before any resource is touched. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- Secret parameters (`secureString`, `secureObject`) leave no copy in deployment history or logs, so arrange another way to retrieve them if the deployment needs them later. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- On an object parameter, `properties` makes each listed property mandatory unless its type definition is `"nullable": true`. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- `additionalProperties` defaults to `true`, so an object parameter silently accepts undeclared keys unless you set it to `false` or give it a type definition. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- `items` validates only elements past the last `prefixItems` index, and `items: false` requires the array length to match the prefix schemas exactly. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/parameters))
- Scope functions fail outside their scope: `resourceGroup()` errors in a subscription or management group deployment, and `managementGroup()` works only at management group scope. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-functions))
- `providers` is deprecated; prefer `resourceId` and the other resource functions. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-functions))
- Tooling older than Azure CLI 2.37.0 or Azure PowerShell 7.2.4 breaks the tutorial commands, so check `az --version` before starting. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-tutorial-create-first-template))
- The `2019-04-01` schema date is not stale and needs no update; leaving it in place keeps all current template features available. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-tutorial-create-first-template))
- The tutorial estimates about 12 minutes for the guided steps, but real time depends on how many tools you still need to install. ([Learn](https://learn.microsoft.com/en-us/azure/azure-resource-manager/templates/template-tutorial-create-first-template))
