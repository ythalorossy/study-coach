# Configure self-service password reset (SSPR)

## Key concepts

- Microsoft Entra self-service password reset (SSPR) lets users change or reset their own password, or unlock their account, without an administrator or help desk, cutting help desk calls and lost productivity. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- Users run the flow from the SSPR portal at https://aka.ms/sspr, which resolves to https://passwordreset.microsoftonline.com, usually reached by picking "Can't access your account" in an app. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- SSPR is not switched on for a tenant's users out of the box: every user must first register at least one authentication method before they can reset or unlock anything. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- To configure it you need at least the Authentication Policy Administrator role, a tenant with Microsoft Entra ID P1 licensing, a non-admin test account, and a group to pilot with. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/tutorial-enable-sspr))
- At the portal, Microsoft Entra ID checks account validity, SSPR enablement, the user's organization, where the password is managed, and whether enough policy-approved authentication methods have data. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- Scope for enabling is None, Selected (groups only), or All users, so a pilot group is the usual first step. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/tutorial-enable-sspr))
- In hybrid tenants, Microsoft Entra Connect or cloud sync can send SSPR password changes back to on-premises Active Directory through password writeback. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- Every SSPR change or reset is evaluated against the tenant password policy, and a non-compliant password makes the user try again. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-policy))

## Settings and limits

- Configuration path: Microsoft Entra admin center > Entra ID > Password reset, with Properties, Authentication methods, Registration, Notifications, and Customization pages. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/tutorial-enable-sspr))
- Properties > Self service password reset enabled accepts None, Selected, or All, applied with Save. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/tutorial-enable-sspr))
- Only one Microsoft Entra group can be selected for SSPR in the admin center at a time, although nested groups are supported for bigger rollouts. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/tutorial-enable-sspr))
- Authentication methods > Number of methods required to reset is set to 1 or 2; the tutorial sets 2 because raising it improves security. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/tutorial-enable-sspr))
- Methods available to users include Microsoft Authenticator push notification, Authenticator verification code, software OATH token, hardware OATH token (preview), mobile phone/SMS, voice call, and Email OTP. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- For SSPR, Microsoft Authenticator, software OATH, and hardware OATH each count as one method, so they cannot be combined to satisfy a two-method rule, with or without the centralized Authentication methods policy. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- Registration > Require users to register when signing in is Yes or No; if No, users are not prompted but can self-register at https://aka.ms/ssprsetup or from the Access Panel Profile tab. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- On the Registration page, the day count controlling how often users must reconfirm their authentication information accepts 0 to 730, and 0 means they are never asked; the tutorial uses 180. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- That reconfirm-day setting is only available when Require users to register when signing in is turned on. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- Notifications > Notify users on password resets? set to Yes emails the user's primary and alternate email addresses in Microsoft Entra ID, falling back to the User Principal Name (UPN) if neither exists. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- Notifications > Notify all admins when other admins reset their password? set to Yes emails Global Administrators when a fellow administrator resets their password through SSPR. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/tutorial-enable-sspr))
- Customization > Customize helpdesk link set to Yes plus a Custom helpdesk email or URL supplies a support destination for the "Contact your administrator" link. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/tutorial-enable-sspr))
- Write back passwords to your on-premises directory: Yes lets federated, pass-through authentication, and password hash synchronized users reset; No forces them to an administrator. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- Allow users to unlock accounts without resetting their password: Yes separates unlocking from resetting; No offers only the combined operation, which is the default behaviour of a reset. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- Admin SSPR is turned off by setting AllowedToUseSspr to $false on the tenant authorization policy (Update-MgPolicyAuthorizationPolicy -AllowedToUseSspr:$false), and the change can take up to 60 minutes to apply. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-policy))
- Password rules: 8 to 256 characters, three of four character classes (lowercase, uppercase, digits, symbols), Unicode characters not allowed; accounts lock after 10 wrong passwords for one minute. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-policy))
- Password expiry defaults to no expiration for tenants created in 2021 or later and 90 days for tenants created before 2021; per-user never-expires uses the DisablePasswordExpiration password policy. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-policy))

## Compare and choose

- Mobile app options differ by requirement: with 1 method required only a verification code is offered, with 2 required users get notification or verification code plus the other enabled methods (in tenants not yet on the centralized policy). ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- Registered versus required: 1 or more methods registered with 1 required means able to reset; exactly 1 registered with 2 required means unable to reset; 2 or more registered with 2 required means able. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- Two-gate versus one-gate: two-gate is forced for accounts with Entra administrator roles (for example Global Administrator, Security Administrator, Authentication Policy Administrator, User Administrator), after 30 days of trial, once a custom domain is configured, or when Microsoft Entra Connect syncs identities. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-policy))
- One-gate (a single piece of data such as an email or phone) applies in either of two cases: during the first 30 days of a trial, or when no custom domain is configured (tenant still on *.onmicrosoft.com) and Entra Connect is not syncing identities. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-policy))
- Two-gate needs two pieces of authentication data such as an email, Authenticator, or phone, bans security questions, cannot be changed, and does not depend on the Authentication methods policy. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-policy))
- Change history versus reset history: the previous password cannot be reused during a password change, but it can be reused when resetting a forgotten password; change history depends on writeback. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-policy))
- Notify users on password resets targets the resetting user; notify all admins targets Global Administrators about admin resets, so set both to Yes for full coverage. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/tutorial-enable-sspr))
- Unlock without resetting: choose Yes where help desks want unlock separated from a password change, and No (combined) where a reset should always clear the lockout. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))

## Gotchas

- Microsoft Authenticator can never be the only method: add at least one more method when 1 is required and at least two more when 2 are required. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- Raising the requirement from 1 to 2 immediately blocks everyone who registered a single method; they see an error page and must ask an administrator. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- Changing which methods are available also breaks access, for example dropping security questions in favour of mobile phone plus alternate email strands users who only had the old data. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- Users can dismiss the registration prompt with cancel or by closing the window, but are prompted again at every sign-in until registration completes; it appears once per interactive session and does not end an existing session. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks)) ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/tutorial-enable-sspr))
- Users must sign in before they can reconfirm their information, and when two methods are required, deleting a method does not force reconfirmation until the configured day count is reached. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- Stale or wrong contact data can make a reset fail; an admin can enter it, or users register at https://aka.ms/ssprsetup, https://aka.ms/setupsecurityinfo, or https://aka.ms/mfasetup. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/tutorial-enable-sspr)) ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- Legacy MFA and SSPR policies: authentication methods can no longer be managed there as of September 30, 2025, so migrate to the centralized Authentication methods policy. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/tutorial-enable-sspr))
- On-premises password policies never display in SSPR, and users with writeback see no password strength indicator, because cloud rules cannot evaluate on-premises requirements. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/tutorial-enable-sspr))
- Federated users can wait up to 2 minutes after "Your password has been reset" before the synchronized password works, because on-premises is the source of authority. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/tutorial-enable-sspr))
- Administrator accounts have SSPR enabled by default and must use two methods, so always test with a non-administrator account such as testuser. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/tutorial-enable-sspr))
- If SSPR for admins is disabled they cannot reset even when in scope of the user policy, and while registration is on they are still prompted but told they cannot register methods, so exclude admins from the user SSPR policy. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-policy))
- Microsoft account guests from Hotmail.com, Outlook.com, or similar personal addresses cannot use Microsoft Entra SSPR. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- The "Don't lose access to your account!" page title only appears for users who are members of the SSPR or combined registration groups configured for the tenant. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/tutorial-enable-sspr))
- SSPR notification emails come from cloud-specific senders such as msonlineservicesteam@microsoft.com in public cloud, @oe.21vianet.com in Azure operated by 21Vianet, and @azureadnotifications.us for US Government, and spam rules often block them. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- The portal language follows the browser locale; add ?mkt= and a locale, for example https://passwordreset.microsoftonline.com/?mkt=es-us, to force a language. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- Third-party on-premises password filters must be configured to cover the admin password reset scenario if SSPR should enforce them; Microsoft Entra password protection for AD DS works out of the box. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks))
- To retire SSPR, set Self service password reset enabled to None on the Properties page and save; leave it enabled if you plan to add writeback. ([Learn](https://learn.microsoft.com/en-us/entra/identity/authentication/tutorial-enable-sspr))
